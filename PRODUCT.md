# Product

## Register

product

## Users

The primary user is a MENA Ignite hackathon judge evaluating the product for the first time on a laptop or presentation screen. The judge needs to understand the problem, run the core demonstration, and verify the AI and Nokia/CAMARA integration within minutes. Technical reviewers are the secondary users; they need inspectable evidence, architecture, safety boundaries, and honest integration provenance.

## Product Purpose

HISN-OT prevents valid-credential attacks from becoming unsafe industrial actions. It holds a command, lets a bounded LangGraph agent select trusted Nokia/CAMARA network evidence, and gives final authority to a deterministic safety policy. Success means a first-time viewer can see that an unsafe request was blocked, the accepted plant state did not change, and every external or simulated result is labeled accurately.

## Brand Personality

Credible, controlled, transparent. The interface should feel like a calm operational instrument that earns trust through visible proof. It should make advanced engineering understandable without looking simplified to the point of being fictional.

## Anti-references

Avoid dense control rooms that expose every instrument at once, cyberpunk dashboards built from tiny uppercase text, decorative command centers, generic SaaS card grids, unexplained acronyms, hidden provenance, and animations that compete with the safety result.

## Design Principles

1. Lead with the five-second story: command, network proof, decision, physical outcome.
2. Give the demonstration one obvious starting action and reveal advanced controls only when useful.
3. Show proof beside every claim, using consistent language for live, sandbox, local, simulated, and unavailable states.
4. Keep the outcome visible while technical evidence expands progressively beneath it.
5. Preserve the distinction between AI advice, deterministic authorization, and simulated plant behavior.

## Accessibility & Inclusion

Target WCAG 2.2 AA. Support complete keyboard operation, visible focus, reduced motion, screen-reader status announcements, color-independent state communication, readable sentence-case copy, and responsive layouts from 360-pixel mobile screens through projector viewports.
